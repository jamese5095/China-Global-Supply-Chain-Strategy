# 中国企业国际供应链机会与能力布局

静态研究看板。根目录含 `index.html`，可直接打开，也可用静态服务预览。无需安装前端依赖，不调用在线地图或图表库。

- 公开仓库：https://github.com/jamese5095/China-Global-Supply-Chain-Strategy
- GitHub Pages：https://jamese5095.github.io/China-Global-Supply-Chain-Strategy/

## 内容

- 首页：北越、德国、泰国三个建设方向，以及一条单列的进口设备业务线索。
- 详情：客户变化、具体货流、服务需求、进入条件、建设选择、决策结论六步推导。
- 证据：点击依据打开侧边说明，可访问原始公开资料；内部资料仅保留必要的客户关系摘要。
- 贸易：沿用用户提供的2025年六行业代表商品数据，独立比例、保留口径，不用于直接推算物流收入或仓位。

页面无上传、编辑、下载原始资料或资料管理入口；未附客户原表、收入金额和内部文件。仅供只读研究展示。

## 本地打开

直接打开 `index.html`。也可在本目录启动静态服务，然后访问对应本机地址。

## 更新与新增建议

编辑 `tools/prepare_data.py` 中的结构化内容，然后运行 `python3 tools/prepare_data.py`，更新 `data.json` 和浏览器使用的 `data.js`。`data.json` 为生成快照，不要只改该文件。

每条建议需唯一且稳定的 `id`，以及：地区、行业、客户、现状事实、货流、服务需求、进入条件、能力建设、决策及来源ID。来源共用同一个库；新增来源说明其支持范围与使用条件。模板自动生成卡片、筛选、详情和证据侧栏。

`首批建设`、`网络延伸`与`进口线索`代表不同建议性质，不应将待确认委托的业务线索标成已闭合投资项目。数字、客户关系、实际委托和分析建议分开维护。

## 文件

- `index.html`：应用入口。
- `styles.css`：响应式页面和打印样式。
- `app.js`：路由、筛选、推导展示及依据侧栏。
- `tools/prepare_data.py`：内容维护与生成。
- `data.js` / `data.json`：生成数据，可离线使用。
- `assets/`：本地品牌素材。

GitHub Pages从 `main` 分支根目录发布。更新内容后生成数据、提交并推送，即可触发网站更新。与此前的六行业看板使用独立仓库。
